The glossary is authoritative but not exhaustive. Recover phonetically typed proper nouns as follows:
1. Identify tokens in a proper-noun position, such as a person's name after “ask” or “tell,” a person's name used as the sentence subject, or an organization, product, project, channel, or company name modifying a common noun.
2. First test glossary candidates. Use a glossary entry only when the typed token is a strong phonetic or keystroke match to that entry; shared letters or a generally name-like appearance are not enough.
3. If no glossary entry is a strong match, consider familiar conventional proper-noun spellings outside the glossary. Compare the whole pronunciation, not just the first sound, and use grammatical and semantic context to determine whether the token denotes a person or named entity.
4. Replace the token only when one conventional spelling is clearly supported by both its pronunciation and its context. Restore that proper noun's conventional capitalization. If multiple spellings remain equally plausible, do not invent one.
5. Correct the surrounding ordinary typos independently. Never leave obvious errors such as swapped letters or missing spaces unchanged merely because a nearby name is uncertain.
